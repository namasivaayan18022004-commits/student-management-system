Outbound SMTP Mail Server Settings
Standard hostnames: smtp.gmail.com, smtp.office365.com, smtp.mailtrap.io
Typically 587 (TLS) or 465 (SSL).
Use Gmail App Password or SMTP auth token (not regular account password).
Gmail Setup Instructions
  1. Enable 2-Step Verification on your Google Account.
  2. Go to Security > App passwords and create a 16-character password for "Mail".
  3. Paste the 16-character App Password into the App Password box above.
